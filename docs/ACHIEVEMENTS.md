# Karaoke Battle 成就系統

- **規模**：共 64 項成就，102 個目標（分階成就每一階各算一個），滿分 6430 點。
- **分階**：多數累積型成就分銅、銀、金三階，其他是一次完成的單項成就。
- **怎麼算**：只計算有評分的正式演唱。
- **永久保留**：達成後就算刪掉錄音也不會收回。
- **存放位置**：存在資料夾的 `achievements.json`，跟著資料一起搬移。
- **點數**：依難度分 10／20／50／100／200 五級（原本的兩倍）。累積點數只增不減；在個人資料的「我的背包」可以用點數兌換道具（修音魔杖 5 點、共鳴結界 20 點、弱點眼鏡 500 點；每天 05:00 也會免費補到魔杖 5 支、結界 2 個，第一次開啟再送 50 點），花掉的另外記，不影響成就統計。

**資料來源（備註）**
- **語言**：依序看熱門歌單的分語言榜、YouTube 標示的語言、加歌時選的語言。
- **曲風**：只認得熱門歌單上的歌，用歌名比對，曲風取自熱門歌單的標籤；要先打開過熱門歌單才會有資料。
- **年代**：依序看熱門歌單的發行年份、YouTube 音樂資訊裡的發行年份；不用上傳日期。
- **歌手**：先用熱門歌單上的歌手；比對不到的 YouTube 歌用影片的音樂資訊，沒有的話用頻道名稱（翻唱會算成翻唱的人）。
- **點亮星星**：App 無法確認是否真的按了星星，從側邊欄「賞我星星」打開 GitHub 頁面就算達成。
- **挑戰者**：要是匯入之後才唱的同一首歌才算，每個重播只算一次。

## 8. 隱藏成就（達成前只顯示「???」，點數是同等難度的兩倍）

| 成就 | 條件 | 點數 |
|---|---|---|
| 夜貓子 | 凌晨 0 點到 5 點唱完一首 | 50 |
| 早起的鳥兒 | 早上 7 點到 9 點之間唱當天第一首歌 | 50 |
| 狀態極佳 | 當天第一首就拿 S 以上 | 100 |
| 高音王 | 唱到比你音域最高音還高 3 Key 的音 | 100 |
| 低音王 | 唱到比你音域最低音還低 3 Key 的音 | 100 |
| 馬拉松 | 一天內唱 20 首 | 200 |
| 完美 100 | 拿到 100 分（總分顯示 100.0；用道具唱到的也算） | 200 |

- **高音王／低音王**：要先在設定或熱門歌單量過音域。只看唱在歌曲音符上的音：和該音符相差 4 個半音內，差一個八度也算（例如降一個八度唱）；伴奏的嗡聲、換氣和雜音不算，低於 C2（65 Hz）一律當作電源嗡聲；至少要有 1.6 秒。取高點和低點（各去掉 2%），四捨五入到半音後比較。

## 共通規則

- **一天的界線**：一天從凌晨 5 點算到隔天凌晨 5 點，所以半夜唱的歌算前一天。
- **連續天數**：取歷來最長的連續天數。
- **點數級距**：
  - 10 點：新手任務。
  - 20 點：點一下就能完成的分享。
  - 50 點起：實力類（S 50、SS 100、SSS 200）。
  - 100 點：在 GitHub 按星星（感謝支持）。
  - 200 點：要花幾個月的金牌，例如 500 次演唱、50 小時、連續 30 天。
  - 隱藏成就：同等難度的兩倍，時段類 50、其他 100、馬拉松和完美 100 各 200。
- **介面**：
  - 判定需要多說明的成就，名稱旁有圓圈 i。
  - 已達到的階段用銅、銀、金徽章表示。
  - 分階成就下方的圓點可以點，切換查看每一階。
  - 個人資料頁上方有成就統計卡：解鎖數、點數、金銀銅牌數、最新解鎖。
- **解鎖動畫**：
  - 解鎖時播放滿版動畫。
  - 演唱中和分數揭曉時會等結束後才出現。
  - 第一次開啟 App 時，依過去的紀錄一次補齊，只顯示一則總結。
